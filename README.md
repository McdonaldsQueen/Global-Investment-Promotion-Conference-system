# 主会场嘉宾工作台使用说明

每天拿到最新的主会场 Excel 后，用这个工作台看有多少家企业确认参会，并下载整理好的名单。

## 第一步 打开网址

用电脑浏览器打开经办人发给你的**工作人员专用网址**。看到「工作台已就绪。请选择当天的 Excel。」就可以开始了。转发时，请把整条网址发给相关工作人员。

## 第二步 上传当天的 Excel

点击「**选择 Excel 文件**」，选当天从报名系统导出的主会场 Excel（.xlsx）。看到「导入成功」后，核对页面上的文件名和「数据日期」。日期不对，可以在页面上改成这份名单对应的日期。

## 第三步 看结果

点击「**数据看板**」。想知道一共有多少家确认参会，看「确认参会企业集团」。想看具体是哪几家，点卡片里的「查看明细」，也可以输入公司名搜索。

- **各邀请单位企业进度**显示每个单位邀请的企业有多少家确认、多少家待确认。
- **跨单位重复邀请**显示同一家集团被哪些单位邀请，以及各单位填报了哪些嘉宾。

## 第四步 下载需要的表

- **要完整名单**，点页面上方的「下载 Excel」。如果按钮显示「下载 Excel（含待复核）」，打开文件后先看「待复核」工作表。
- **要核对确认企业**，点看板里的「导出确认企业 Excel」。打开文件后，先看「确认参会集团」汇总，再到「确认企业全部明细」查看对应嘉宾、邀请来源和原表行号。

## 核对名单

**发现资料填错或缺项**，点「待复核」，按提示找到原表行号，再点该行的「复核」。核对后修改并点「保存复核」。不确定时，先向填报单位确认。修改完成后，再下载一份新表。

**发现同一集团被拆成好几家**，点「集团名称」，搜原来填写的单位名称，点「统一名称」，填入核实后的集团全称，再点「保存复核」。有几种不同写法，就把这些写法分别改成同一个集团名。

## 看数字时注意

- **确认参会**指这家企业至少有一位嘉宾填了姓名和职务。嘉宾国籍缺失会提示补填，企业仍计为确认。
- **同集团只计一家**。集团下有几位嘉宾，明细仍可分别查看。序号填「例」的示例行会自动跳过。
- **同一家企业可能出现在几个单位的进度里**。例如两个单位都邀请了同一集团，两个单位各有一条记录，总数按集团只算一家。

## 遇到问题怎么办

- **打开后还让选配置文件**，请用经办人发来的完整专用网址重新打开。用电脑浏览器粘贴整条网址，看到「工作台已就绪」再上传。
- **找不到下载文件**，先看浏览器的「下载」列表。页面上出现「手动保存已生成文件」时，也可以点它保存。
- **选错文件或要处理第二天的名单**，先下载需要保留的结果，再点「选择 Excel 文件」导入另一份。网页只处理当前选中的文件。

上传的名单在自己的浏览器里处理。请在关闭或刷新网页前下载需要保留的结果。
