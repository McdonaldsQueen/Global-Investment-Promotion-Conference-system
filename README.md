# 深圳全球招商大会 · 主会场嘉宾工作台

从浏览器导入每日主会场 Excel，查看确认参会、各邀请单位进度和跨单位重复邀请，并下载整理表或确认企业核验表。

## 使用

打开网站或在电脑上用浏览器打开 `docs/index.html`，先选择由经办人单独提供的工作台配置 JSON，再选择每日导出的 `.xlsx` 文件。两个文件均由浏览器本地读取。每次重新打开页面时需重新选择配置。

## 维护

`src/` 是网页源码和随附依赖。修改后运行 `python build.py` 重新生成可独立打开的 `docs/index.html`。此命令使用 Python 标准库。

GitHub Pages 的发布源为 `main` 分支的 `/docs` 目录。请提交更新后的 `docs/index.html`。
