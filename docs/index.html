操作指引

  1. 用工作人员专用链接打开网页。点击「选择 Excel 文件」，上传当天从报名系统导出的主会场名单。上传后核对文件名和数据日期。
  2. 点「确认参会集团」查看确认企业和嘉宾明细，也可以下载确认企业 Excel。同一集团只计一家；至少一位嘉宾填了姓名和职务就计为确认。
  3. 点「重点企业候选」，按企业机构性质筛选，再按职级查看嘉宾。筛选结果可以单独下载。
  4. 点「数据看板」，查看各单位确认和待确认企业数、外资国家分布及跨单位重复邀请。需要汇报时，点击「复制汇报摘要」。
  5. 点「待复核」，按原表行号核对缺项或冲突。需要查榜单、统一集团名称或查看整理后的嘉宾行，点导航里的「⋯」。
  6. 点页面上方「下载 Excel」保存完整名单。刷新网页或换一份名单前，先下载需要保留的结果。
